## 🚀 Proyectos destacados
 
### 🎨 Lonepixell — Creative Web Agency
Experiencias web nivel Awwwards con Next.js + React 19 + GSAP + Lenis. Construí un **ecosistema modular de skills de Claude Code** (`wow-pipeline`, `hero-craft`, `motion-craft`, `visual-craft`, `copy-adaptation`, `responsive-craft`, `landing-page-strategy`) para producir sitios premium de forma sistemática — de brief a hero animado sin perder el arte.
 
### 🌉 Enterprise Integration @ NTT DATA
Integración de sistemas críticos para operadores de telecom: puentes **SOAP legacy ↔ REST moderno**, orquestación de mensajería con IBM MQ, resolución de casos peludos de ESQL (CDATA null pointers, cualquiera que haya tocado ACE sabe) y optimización de pipelines CI/CD con Jenkins.
 
### 🤖 Claude Usage Monitor
Sistema multi-componente que armé para mí: microservicio en Node.js sobre mi VPS + widget de **Scriptable en iPhone** + push notifications con **ntfy**. Porque saber cuánto Claude te queda no debería requerir abrir una web.
 
### 🧰 Single-file Tools
Colección de apps útiles en un solo archivo HTML — desde un tracker de gastos con lógica de **split por quincena** hasta utilidades personales. La filosofía: si lo uso a diario, lo construyo yo.
